# Date Planner PRD

## 서비스 개요

여러 커플이 각자의 독립된 공간에서 가고 싶은 장소를 저장하고 데이트 일정을 공동으로 관리하는 모바일 웹/PWA입니다. 다른 커플의 데이터에 접근할 수 없도록 커플 단위 권한 경계를 설계합니다.

## MVP 범위

카카오 로그인, 커플 초대·연결, 장소 검색 및 공동 저장, 장소 목록·지도 조회, 데이트 일정 작성·조회·수정, 기본 설정을 단계적으로 제공합니다. 오프라인 편집, 채팅, 추천 알고리즘, 푸시 알림은 별도 검토 범위입니다.

## TASK-01 범위

pnpm Workspace, React 화면과 라우팅, Query Provider, 모바일 레이아웃, PWA 셸, NestJS API 기본 설정과 Health, PostgreSQL Compose, 빈 Prisma 스키마, 공통 타입, 코드 품질 명령과 개발 문서를 구성합니다. 인증과 실제 장소·일정·지도·공유 수신 기능은 포함하지 않습니다.
